### Project Overview

Developed an interactive UPI Transaction Analytics Dashboard using Advanced Microsoft Excel to analyze 502,887 UPI transactions worth ₹44.25 crore.

The project focuses on understanding digital payment behaviour, transaction success and failure patterns, UPI application performance, bank-wise transaction distribution, merchant activity, cashback economics, geographical trends and potential fraud indicators.

The objective was to transform raw transaction data into meaningful business insights and actionable recommendations that can support payment operations, financial monitoring and risk management.

## Business Objectives

- Monitor overall UPI transaction volume and transaction value.
- Evaluate successful, failed, pending and refunded transactions.
- Compare transaction performance across UPI applications.
- Analyze bank-wise and state-wise transaction distribution.
- Identify high-value transaction types and merchant segments.
- Understand daily, hourly and day-of-week transaction patterns.
- Monitor cashback, transaction fees and financial efficiency.
- Identify suspected fraud patterns and potential risk areas.

## Tools & Technologies

### Key Business Insights

### 1. UPI Application Performance

- PhonePe dominates transaction volume with approximately 49.75% share.
- Google Pay contributes 21.31%.
- Paytm accounts for 14.34%.
- The top three UPI applications collectively contribute approximately 85.40% of transactions.


### 2. Transaction Status Analysis

- Approximately 91.05% of transactions are successful.
- Failed transactions account for approximately 6.95%.
- Pending transactions account for approximately 1.96%.
- Refunded transactions represent approximately 0.04%.



### 3. Transaction Type Analysis

Transaction value is distributed across the following categories:

| Transaction Type | Amount |
|---|---:|
| P2M | ₹18.88 Cr |
| P2P | ₹8.77 Cr |
| Bill Payment | ₹6.17 Cr |
| Online Shopping | ₹3.83 Cr |
| Recharge | ₹3.54 Cr |
| Subscription | ₹1.79 Cr |
| Wallet Transfer | ₹1.26 Cr |



### 4. Bank-wise Performance

- HDFC Bank leads with approximately ₹5.89 Cr.
- SBI contributes approximately ₹5.84 Cr.
- Kotak Mahindra Bank contributes approximately ₹5.58 Cr.
- Canara Bank and ICICI Bank contribute approximately ₹5.52 Cr and ₹5.51 Cr, respectively.



### 5. Geographical Analysis

Maharashtra, Karnataka, Delhi, Rajasthan and Uttar Pradesh are among the leading states by transaction value.

The displayed state-wise transaction values are relatively close, suggesting broad participation across the leading regions.



### 6. Time-Based Transaction Analysis

- Daily transaction values show fluctuations throughout the month.
- Hourly analysis indicates stronger transaction activity during evening hours.
- The day-and-hour heatmap helps identify recurring periods of higher transaction activity.

**Business implication:** Peak-hour monitoring can help improve transaction processing capacity and payment reliability.

### 7. Fraud & Risk Monitoring

- The dashboard identifies 17,089 suspected fraud flags.
- Risk-score information supports further investigation and segmentation.


### 8. Cashback & Transaction Fee Analysis

- Total cashback: ₹34.63 lakh.
- Total transaction fees: approximately ₹5.20 lakh.
- Dashboard cashback-to-fees ratio: 6.66x.
